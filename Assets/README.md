# Assets Directory Structure

```
Assets/
├── Sprites/           # All pixel art graphics
│   ├── Characters/    # Player and NPC sprites
│   ├── Enemies/       # Zombie, mutant, raider sprites
│   ├── Items/         # Weapon, armor, consumable icons
│   ├── Buildings/     # Structure and furniture sprites
│   ├── Tileset/       # Ground, wall, floor tiles
│   ├── UI/            # UI elements and icons
│   ├── Effects/       # Particle effects, blood, impacts
│   └── Environment/   # Trees, rocks, water, props
├── Prefabs/           # Reusable game object templates
│   ├── Player/        # Player character prefab
│   ├── NPCs/          # NPC prefab variants
│   ├── Enemies/       # Enemy prefab variants
│   ├── Items/         # Item pickup prefabs
│   ├── Buildings/     # Building structure prefabs
│   └── UI/            # UI panel prefabs
├── Scenes/            # Game scenes
│   ├── MainMenu.unity
│   ├── CharacterCreation.unity
│   ├── GameWorld.unity
│   ├── Shelter.unity
│   └── DeathScreen.unity
├── Audio/             # Sound and music files
│   ├── Music/
│   │   ├── Exploration/
│   │   ├── Combat/
│   │   ├── Boss/
│   │   └── Ambient/
│   └── SFX/
│       ├── Weapons/
│       ├── UI/
│       ├── Footsteps/
│       ├── Crafting/
│       └── Ambient/
├── Materials/         # Unity materials for graphics
├── Animations/        # Animation clips
└── Settings/          # Game configuration files
```
